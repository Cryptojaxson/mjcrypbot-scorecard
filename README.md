# MJcrypbot Scorecard

A phone app for the `/score` results of MJcrypbot (Binance futures alerts → Telegram).

- **Scorecard**: one card per alert type and side, with the same ✅ 🛑 🌊 ⏳ ❌ marks the bot uses. Tap a card to see which gates it passes.
- **What-if**: try other gate values and copy the matching `settings.txt` lines.
- **Update**: paste the bot's `/score` reply to load new numbers. They are saved only in your phone's browser.

Open the GitHub Pages link on your phone and choose **Add to Home screen** to install it.

This repo holds only the app page. No bot code, API keys or trading data are stored here.
